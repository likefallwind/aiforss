## 项目：智能教育辅导系统

### 你将学到什么
- 如何调用大模型API实现苏格拉底式智能辅导对话
- 如何追踪学生知识点的掌握程度并动态更新
- 如何根据掌握度变化推荐下一步学习内容
- 如何利用大模型进行自动评估与反馈生成

### 环境准备
- Python 3.8+
- 安装依赖：`pip install openai tqdm`
- 配置环境变量：`export OPENAI_API_KEY="your-api-key"`

### 背景介绍
在传统教育中，一位教师难以同时兼顾所有学生的个性化需求。本项目将构建一个简易的智能教育辅导系统，通过大模型实现一对一学科辅导，根据学生的练习表现动态调整学习路径，并提供即时评估与反馈。通过这个项目，你将亲手体验如何将大模型能力落地到真实的教育场景中。

### 任务分解

#### Task 1：智能辅导系统
**目标**：基于大模型实现苏格拉底式引导的问答对话，帮助学生自主发现答案而非直接给答案。
**提示**：在 `answer/main.py` 中，有一个 `tutor_conversation(student_input, history)` 函数负责处理对话。请在 scaffold 中补全提示词构建逻辑——要求模型使用追问、类比、拆分问题等方式引导学生思考，而非直接给出答案。
**对应文件**：`src/main.py`

#### Task 2：掌握度追踪
**目标**：根据学生的答题表现，使用简化的贝叶斯方法动态更新知识点的掌握概率。
**提示**：定义知识点之间的依赖关系（如"配方法"依赖"完全平方公式"）。当学生答对或答错某题时，更新对应知识点的掌握概率——答对提高、答错降低。
**对应文件**：`src/main.py`

#### Task 3：自适应学习路径推荐
**目标**：根据当前的掌握度状态，推荐下一个应该学习或复习的知识点。
**提示**：实现一个 `recommend_next_topic(mastery_state)` 函数。当某知识点掌握度低但其前置知识已掌握时，优先推荐该知识点；当已学知识点即将遗忘时（根据间隔重复原则），主动安排复习。
**对应文件**：`src/main.py`

#### Task 4：自动评估与反馈生成
**目标**：利用大模型对学生答案进行评分并生成个性化反馈。
**提示**：调用大模型API，将学生答案与标准答案对比，输出评分和具体的改进建议。
**对应文件**：`src/main.py`

### 项目结构
- `src/main.py`（脚手架）：包含智能辅导、掌握度追踪、学习路径推荐、自动评估四大核心任务的框架代码
- `answer/main.py`（参考答案）：基于scaffold补全的参考实现，完整实现四大核心功能
- `tests/test_answer.py`（测试文件）：pytest 测试，只验证 answer 目录下的参考实现

### 验收标准
- [ ] `tutor_conversation` 函数能够生成引导式回复，而非直接给答案
- [ ] `update_mastery` 函数能正确更新知识点的掌握概率
- [ ] `recommend_next_topic` 函数能根据掌握状态推荐合理的后续学习内容
- [ ] `evaluate_answer` 函数能对客观题进行评分并给出改进建议
- [ ] 运行 `python answer/main.py` 可完整演示四个功能的协同工作流程

### 挑战任务（选做）
- **多轮对话记忆**：将对话历史引入 `tutor_conversation`，让模型能够记住之前的讨论内容并基于此继续引导
- **难度自适应调整**：根据学生连续答对或答错的情况，自动调整下一道练习题的难度参数
