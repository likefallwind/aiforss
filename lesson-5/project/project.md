## 项目：以人为本的大模型：价值对齐与个性化

### 你将学到什么
- 理解人机对齐的核心概念与价值建模理论基础
- 掌握RLHF强化学习人类反馈的实现方法
- 掌握DPO直接偏好优化的简化实现
- 学会构建用户画像并实现个性化内容生成

### 环境准备
- Python 3.8+
- PyTorch 2.0+
- transformers 库
- 无需外部API Key，使用模拟数据进行演示

### 背景介绍
随着大语言模型在社会科学研究中的广泛应用，确保AI系统的行为与人类意图一致变得至关重要。本项目将通过简化实现，让你亲手体验RLHF和DPO这两种主流的价值对齐技术，并通过用户画像系统实现个性化内容生成。

### 任务分解

#### Task 1: 偏好数据的模拟与处理
- **目标**: 理解价值对齐中"好输出vs坏输出"的偏好框架，模拟生成人类偏好数据
- **提示**: 使用简单的评分函数模拟人类对输出的偏好打分，构造偏好对数据
- **对应文件**: `src/main.py` 中的 `simulate_preference_data` 函数

#### Task 2: 实现简化的RLHF流程
- **目标**: 实现奖励模型训练和基于奖励信号的策略优化
- **提示**: 奖励模型学习预测人类偏好分数；策略优化使用奖励信号更新模型
- **对应文件**: `src/main.py` 中的 `RewardModel` 类和 `rlhf_training_step` 函数

#### Task 3: 实现DPO直接偏好优化
- **目标**: 将RLHF的三阶段流程简化为直接的偏好优化
- **提示**: DPO通过对比偏好对数据直接优化策略，无需显式训练奖励模型
- **对应文件**: `src/main.py` 中的 `dpo_loss` 函数

#### Task 4: 构建用户画像与个性化生成
- **目标**: 基于用户交互历史构建画像，实现个性化内容生成
- **提示**: 统计用户偏好特征，融合用户画像调整内容生成策略
- **对应文件**: `src/main.py` 中的 `UserProfile` 类和 `personalized_generate` 函数

### 项目结构
- `src/main.py`（脚手架）：包含RLHF、DPO实现和用户画像系统的完整脚手架代码
- `answer/main.py`（参考答案）：基于src/main.py补全所有TODO的参考答案实现
- `tests/test_answer.py`（测试文件）：pytest 测试，只验证 answer 目录下的参考实现

### 验收标准
- [ ] 成功模拟生成偏好数据，包含prompt、正回答、负回答
- [ ] 实现奖励模型，能够对输出进行偏好评分
- [ ] 完成RLHF训练步骤的单步迭代
- [ ] 实现DPO损失函数并计算优化目标
- [ ] 构建用户画像，能够统计用户偏好特征
- [ ] 实现基于用户画像的个性化内容生成函数
