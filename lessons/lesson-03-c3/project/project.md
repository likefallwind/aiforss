## 项目：大模型金融文本分析系统

### 你将学到什么
- 掌握使用大模型从年报、新闻等金融文本中抽取关键结构化信息的方法
- 理解金融领域情绪分析与通用情感分析的区别，学会构建金融情绪指标
- 学会基于文本分析结果进行风险评估与信用评分
- 了解大模型在市场预测与情景模拟中的应用思路

### 环境准备
- Python 3.9+
- 安装依赖：`pip install openai langchain-core`
- 配置 API Key：设置环境变量 `OPENAI_API_KEY`，或使用支持 OpenAI 接口的大模型
- 本项目使用模拟数据演示核心流程，实际使用时可替换为真实 API 调用

### 背景介绍
金融领域充斥着大量非结构化文本——年报、招股书、新闻报道、分析师研报。这些文本蕴含丰富的决策信息，但传统方法难以高效提取。本项目将通过四个递进任务，带你掌握大模型赋能金融文本分析的核心技能：信息抽取→情绪量化→风险评估→情景模拟。

### 任务分解

#### Task 1：金融文本信息抽取
**目标**：从公司年报摘要中提取关键财务指标与战略信息，转化为结构化数据。

**提示**：观察 `financial_report` 样本文本，使用大模型（或规则模拟）提取：营收增长、研发投入、战略重点等字段。金融文本信息抽取的关键是识别数字、趋势描述和优先级表达。

**对应文件**：`src/main.py` 中的 `extract_financial_info` 函数（第 15-30 行）

---

#### Task 2：金融情绪量化分析
**目标**：对财经新闻进行金融领域情绪分析，理解金融情绪与通用情感的区别。

**提示**：金融情绪分析需要识别：隐含信息（如"三年来首次"暗示拐点）、管理层可信度、短期冲击 vs 趋势性变化。使用 `analyze_financial_sentiment` 函数对新闻文本进行多维度情绪评估。

**对应文件**：`src/main.py` 中的 `analyze_financial_sentiment` 函数（第 35-55 行）

---

#### Task 3：风险评估与信用评分
**目标**：基于文本分析结果，综合评估公司或资产的风险等级与信用评分。

**提示**：风险评估需要综合考虑：财务健康度（从 Task 1 获取）、市场情绪（从 Task 2 获取）、行业环境、宏观因素。设计一个加权评分模型，给出综合风险等级。

**对应文件**：`src/main.py` 中的 `calculate_risk_score` 函数（第 60-80 行）

---

#### Task 4（选做）：市场情景模拟
**目标**：设定不同假设条件，模拟市场可能的反应路径。

**提示**：使用蒙特卡洛思维，设定变量（如利率变化、政策调整）并模拟多种情景。理解大模型在情景生成中的作用——快速生成合理的情景描述与概率分布。

**对应文件**：`src/main.py` 中的 `simulate_scenarios` 函数（第 85-100 行）

### 项目结构
- `src/main.py`（脚手架）：核心练习文件，包含金融信息抽取、情绪分析、风险评估、情景模拟四个任务函数
- `answer/main.py`（参考答案）：参考实现，包含四个任务函数的完整代码与详细注释
- `tests/test_answer.py`（测试文件）：pytest 测试，只验证 answer 目录下的参考实现

### 验收标准

- [ ] Task 1：`extract_financial_info` 能从年报文本中正确提取营收增长、研发方向、战略重点等结构化字段
- [ ] Task 2：`analyze_financial_sentiment` 能识别金融文本中的隐含情绪，给出"短期冲击"、"趋势恶化"等金融专属标签
- [ ] Task 3：`calculate_risk_score` 综合 Task 1&2 结果，输出风险等级（A/B/C/D）和信用评分（0-100）
- [ ] Task 4：`simulate_scenarios` 能生成至少 3 种情景及其概率分布
- [ ] 代码可运行：运行 `python src/main.py` 无报错，所有函数有合理返回值

### 挑战任务

1. **多新闻情感聚合**：将同一公司的多条新闻情绪分析结果聚合为该公司综合情绪指数，思考时间衰减与权重分配
2. **风险预警系统**：基于历史财务报告的时间序列，设计一个风险预警模型，能识别财报中风险因素的变化趋势
