# 使用 OpenAI API 的 Function Calling 示例

好，现在我们来聊一个技术性更强一点的话题，叫Function Calling。这个词你可能在看API文档的时候见过，但你可能不太清楚它到底是干什么的、为什么重要。我先给你解释清楚它的基本原理。我们之前讲的人机对话，模型其实只能「说话」，你问它答，它说的内容都是来自它的训练数据。但现实应用中，我们经常需要它不仅能说话，还要能「做事」。比如你让它查一篇论文，它得有办法真的去查，而不是胡说八道。Function Calling就是让大模型从「只能说话」升级到「能做事」的关键技术。原理是这样的：开发者先预先定义一组函数，每个函数都有自己的名称、参数说明和返回类型。然后当用户提问的时候，模型会根据对话上下文，判断这个问题是否需要调用某个函数，如果需要，它就生成符合函数签名的参数，告诉你「我需要调用这个函数」。这时候应用程序会真的去执行这个函数，把结果返回给模型，模型再根据真实结果生成最终回答。听起来可能有点抽象，我们来看下一张的具体代码示例，你就明白了。
