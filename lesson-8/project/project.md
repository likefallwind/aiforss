## 项目：算法偏见检测与公平性度量

### 你将学到什么
- 理解算法偏见的三层来源：训练数据、模型架构、目标函数
- 掌握公平性度量指标的计算方法：统计均等、均等机会、均等机会
- 实现基于数据重采样的偏见消解技术
- 学会从「技术指标+社会价值」双维度评估模型公平性

### 环境准备
- Python 3.8+
- pandas, numpy, scikit-learn
- 无需 API Key，纯本地算法练习

### 背景介绍
招聘筛选 AI 系统在训练时使用了某公司过去十年的简历筛选记录，而这十年间技术岗位男性占比 80%。当这个模型部署后，它会继续强化这种性别分布——即使候选人本身的能力分布是均衡的。本项目将模拟这个场景，检测模型偏见并尝试消解。

### 任务分解

**Task 1: 模拟带偏见的招聘数据**
- 目标：生成一份包含历史偏见的模拟招聘数据集
- 提示：数据中「被录用」标签与性别存在相关性，即使能力特征分布相同
- 位置：src/main.py 的 `generate_biased_recruitment_data()` 函数

**Task 2: 实现公平性度量指标**
- 目标：计算统计均等、均等机会、均等机会等公平性指标
- 提示：比较模型在不同受保护属性（如性别）群体上的预测结果分布
- 位置：src/main.py 的 `compute_fairness_metrics()` 函数

**Task 3: 偏见消解与效果评估**
- 目标：使用数据重采样技术消解偏见，对比消解前后的公平性指标
- 提示：在保持模型准确率的前提下，提升公平性指标
- 位置：src/main.py 的 `debias_by_resampling()` 函数

### 项目结构
- `src/main.py`（脚手架）：脚手架文件，定义数据生成、偏见检测、公平性度量、偏见消解的函数框架
- `answer/main.py`（参考答案）：参考实现，包含 Task 1-3 的完整代码
- `tests/test_answer.py`（测试文件）：pytest 测试，只验证 answer 目录下的参考实现
