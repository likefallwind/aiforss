## 项目：算法偏见检测与公平性度量

### 你将学到什么
- 理解算法偏见的三大来源：训练数据偏见、模型架构偏见、目标函数偏见
- 掌握社会刻板印象检测的方法，能够识别性别、种族、地域等维度的偏见
- 学会计算三种公平性指标：统计均等性差异、均等机会差异、校准性偏差
- 运用数据重采样与对抗训练方法进行偏见消解

### 环境准备
- Python 3.8+
- 依赖：numpy、pandas（已在项目目录中配置）
- 无需外部 API Key，本项目使用内置模拟数据集

### 背景介绍
算法偏见是人工智能系统中的重要伦理问题。当招聘系统倾向于拒绝女性简历、信贷模型对少数族裔给出更低信用评分时，这些歧视往往源于训练数据中的历史偏见、模型架构的放大效应或优化目标的偏差。本项目将使用模拟的招聘数据集，带领你完整走一遍偏见识别→测量→消解的全流程。

### 任务分解
**Task 1: 偏见来源诊断**（对应文件：src/main.py）
- **目标**：分析数据集的样本分布，识别训练数据中的潜在偏见来源
- **提示**：检查敏感属性（性别、地区）在各特征中的分布差异；查看正类标签在不同群体间的比例；思考这些差异可能如何被模型学习
- **输出**：诊断报告，包含各群体的样本量、正类率、特征均值对比

**Task 2: 公平性指标计算**（对应文件：src/main.py）
- **目标**：实现三种公平性指标的计算函数，量化模型的偏见程度
- **提示**：统计均等性差异 = P(Ŷ=1|A=1) - P(Ŷ=1|A=0)；均等机会差异需区分真实标签；校准性需计算分桶后的实际正类率与预测概率的差距
- **输出**：三个指标的具体数值及公平性判定

**Task 3: 偏见消解实验**（对应文件：src/main.py）
- **目标**：应用重采样技术减少训练数据中的偏见，对比消解前后的指标变化
- **提示**：对过采样不足的群体进行上采样；重新训练模型并重新计算公平性指标；观察哪个指标改善、哪个可能恶化（Impossibility Theorem）
- **输出**：消解前后的指标对比表

### 项目结构
- `src/main.py`（脚手架）：脚手架文件，包含偏见诊断、指标计算、消解的代码框架，学生填写 TODO 部分
- `answer/main.py`（参考答案）：参考实现，完整实现所有函数逻辑，可直接运行验证结果
- `tests/test_answer.py`（测试文件）：pytest 测试文件，验证 answer/main.py 中指标计算函数的正确性

### 验收标准
- [ ] 能够运行脚本并输出诊断报告
- [ ] 统计均等性差异计算结果与参考答案误差 < 0.01
- [ ] 均等机会差异计算结果与参考答案误差 < 0.01
- [ ] 校准性偏差计算结果与参考答案误差 < 0.02
- [ ] 重采样消解后至少一个公平性指标有明显改善（变化 > 0.05）
