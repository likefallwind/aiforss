## 项目：舆论传播与社会网络模拟

### 你将学到什么
- 理解多智能体系统的核心架构：状态、行为规则与接口设计
- 掌握社会网络建模方法：如何用图结构表示人际关系
- 掌握智能体通信协议：消息传递与观点更新的实现机制
- 理解涌现行为的概念：从微观个体行为到宏观社会现象的演化

### 环境准备
- **运行环境**：Python 3.10+
- **依赖安装**：`pip install networkx matplotlib numpy`
- **可选依赖**：`pip install pytest`（用于验证参考答案）

### 背景介绍
在社交媒体时代，一条新闻或观点如何在网络上迅速传播？不同人群的观点如何演化、趋同或分裂？本项目将通过构建一个最小的多智能体模拟系统，用代码回答这些问题。我们将模拟一群具有不同初始观点的「智能体」，它们通过社交网络连接、交换信息、调整观点，最终观察整个系统表现出的宏观涌现行为。

### 任务分解

**Task 1：定义智能体（Agent）的核心结构**
- **目标**：实现 Agent 类，包含状态定义、感知方法 decide()、行动方法 act()
- **提示**：智能体的核心状态是 `opinion`（0-1 的连续值）和 `exposure`（已接触观点列表）。decide() 方法根据已暴露的信息更新观点，act() 方法返回当前观点供网络传播。
- **对应文件**：`src/main.py` 中的 `Agent` 类实现

**Task 2：构建社会网络拓扑**
- **目标**：实现 SocialNetwork 类，用图结构连接智能体
- **提示**：使用 NetworkX 的 Barabási-Albert 模型或小世界网络模型生成符合真实社会特征的网络结构。网络需要支持获取邻居节点、查询边关系等操作。
- **对应文件**：`src/main.py` 中的 `SocialNetwork` 类实现

**Task 3：实现智能体通信协议与消息传递**
- **目标**：设计消息传递机制，让智能体能够向邻居传播观点
- **提示**：定义 Message 数据结构包含 sender_id 和 content（观点值）。Simulation 类负责协调每个时间步的信息传播：每个智能体向所有邻居广播自己的观点，邻居接收并调用 perceive() 方法存储。
- **对应文件**：`src/main.py` 中的 `Message` dataclass 和 `Simulation` 类的 run_step() 方法

**Task 4：运行模拟并观察涌现行为**
- **目标**：实现完整的模拟循环，可视化观点演化过程
- **提示**：编写 run_simulation() 函数，初始化网络和智能体，运行多轮迭代，记录每轮的观点分布。最终用 matplotlib 绘制观点随时间的变化曲线，观察是否出现观点极化、共识形成或持续分歧的涌现现象。
- **对应文件**：`src/main.py` 中的 `run_simulation()` 函数

### 项目结构
- `src/main.py`（脚手架）：多智能体社会模拟的脚手架文件，包含 Agent、SocialNetwork、Message、Simulation 类和 run_simulation() 函数的框架，学生需补全 TODO 部分
- `answer/main.py`（参考答案）：基于脚手架的完整参考实现，补全所有 TODO 并包含可视化逻辑
- `tests/test_answer.py`（测试文件）：pytest 测试，只验证 answer 目录下的参考实现

### 验收标准

- [ ] Agent 类能正确初始化状态，decide() 方法能根据暴露信息更新 opinion
- [ ] SocialNetwork 类能生成具有真实特征的社交网络拓扑（平均度数 > 2）
- [ ] 消息传递机制正常工作：每个时间步智能体向邻居传播观点
- [ ] 运行 50 轮模拟后，能观察到至少一种涌现现象（如两极分化或共识形成）
- [ ] 代码输出观点演化的可视化图表（折线图或热力图）

### 挑战任务（选做）

1. **异质影响力**：引入智能体的「权威度」属性（如粉丝数），让高权威智能体对邻居的观点影响更大。观察这如何改变涌现行为。
2. **政策干预模拟**：在模拟中期注入一条「官方信息」（如观点值为 0.5 的权威消息），模拟辟谣或宣传效果，与无干预情形对比。
